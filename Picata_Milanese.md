## Zutaten & Zubereitung

| Zutaten | Zubereitung |
|:---|:---|
| | **Schritt 1 — Panierung vorbereiten** |
| 4 Eier | Eier Gut vermischen. |
| ca. 120g Parmesan | Fein geriebenen Parmesan unter die Eimasse rühren. Es sollte ein dickflüssiger Brei entstehen. Wenn der Brei zu flüssig ist, mehr Parmesan unterrühren. Zu dicker Brei kann mit ein wenig Rahm oder Milch leicht verdünnt werden. |
| | |
| | **Schritt 2 — Fleisch würzen und mehlen** |
| ca. 600g Kalbfleisch | Dünn geschnittenes (ca. 3-5mm) Kalbfleisch trocken tupfen. Alternativ kann auch Poulet oder Schweinefleisch verwendet werden. |
| Salz und Pfeffer | Das Fleisch mit Salz und Pfeffer würzen. |
| etwas Mehl | Gewürztes Fleisch in Mehl wenden,überschüssiges Mehl abklopfen. |
| | |
| | **Schritt 3 — Braten** |
| Butter oder Bratbutter | Reichlich Butter in der Bratpfanne auf mittlere Hitze bringen. Fleisch im Ei-Kase-Brei wenden (voll bedeckt) und in die heisse Pfanne geben. Auf der ersten Seite ca. 2-3 Minuten braten, bis die Panierung goldbraun und Knusprig ist. Wenden und zweite Seite fertig braten. |

---

## Anmerkungen

> Nach dem Braten rasch verzehren, da die Kruste sonnst wieder weich wird.  
> Dazu passt z.B. ein Risotto oder Tomatenspaghetti.
