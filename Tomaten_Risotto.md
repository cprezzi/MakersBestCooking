# Tomaten Risotto

| | |
|---|---|
| **Kategorie** | vegetarisch |
| **Portionen** | 4 Personen |
| **Vorbereitungszeit** | 15 Min. |
| **Kochzeit** | 30 Min. |

---

## Zutaten & Zubereitung

| Zutaten | Zubereitung |
|:---|:---|
| | **Schritt 1 — Vor- u. Zubereitung** |
| 7 dl | In einer separaten Pfanne die Gemüsebouillon heiss machen |
| 1 Zwiebel | Schälen und fein hacken |
| 1 Knoblauchzehe| Schälen und fein hacken|
| 4 EL Olivenöl | In einer zweiten Pfanne warm werden lassen und anschl. Zwiebel darin ca. 2 Min andämpfen |
| 350 g Risottoreis | Im Öl zusammen mit der Zwiebel unter rühren dünsten bis er glasig wird |
| 1 gehackte Knoblauchzehe | kurz mitdünsten |
| 1 dl Rotwein| Glasiger Risotto mit Rotwein ablöschen und hitze sofort reduzieren |
| 1 Dose gehackte Tomaten (ca. 400 g)| Beigeben |
| 300 g Cherry Tomaten | Beigeben |
| | |
| | **Schritt 2 — Köcheln lassen** |
| 7 dl Gemüsebouillon | Die heisse Bouillon unter häufigem Rühren nach und nach dazugiessen, so dass der Reis immer knapp mit Flüssigkeit bedeckt ist. Das ganze ca. 20 min köcheln lassen bis der Reis cremig und al dente ist |
| 50 g Butter | Beigeben |
| 40 g Käse | z.B. Parmesan, Sbrinz, Gruyere beigeben |
| Salz u. Pfeffer | mit Salz und Pfeffer abschmecken |
| | |
| | **Schritt 3 — Anrichten** |
| Basilikumblätter | Risotto auf Teller anrichten und mit Basilikum dekorieren |
