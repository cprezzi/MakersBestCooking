## Zutaten & Zubereitung

| Zutaten | Zubereitung |
|:---|:---|
| | **Schritt 1 — Brot einweichen** |
|ca. 600g Tessinerbrot, 200ml Milch | Brot in kleine Würfel schneiden, in eine Schüssel geben und mit der Milch übergießen. Etwa 15 Minuten stehen lassen, bis das Brot die Flüssigkeit komplett aufgesogen hat. |
| | |
| | **Schritt 2 — Spinat vorbereiten** |
| 650g Blattspinat | Den Spinat kurz in einem Topf mit wenig Wasser erwellen bis er zusammenfällt. Danach in kaltem Wasser abschrecken, gut ausdrücken, damit überschüssiges Wasser entweicht, und fein hacken. Falls TK-Spinat verwendet wird, reichen ca. 450g. |
| | |
| | **Schritt 3 — Teig herstellen** |
| 2-3 Eier (je nach Grösse), 8 EL Mehl, Salz, Pfeffer | Den ausgedrückten Spinat, die Eier und das Mehl zur eingeweichten Brotmasse geben. Mit Salz & Pfeffer würzen. Alles zu einem formbaren Teig kneten. Sollte der Teig zu klebrig sein, noch 1-2 EL Mehl hinzufügen. |
| | |
| | **Schritt 4 — Gnocchi formen** |
|  | Mit zwei Esslöffeln kleine Nocken formen und auf ein Brett oder Backblech auslegen. Wer flink arbeitet, kann die Noken auch direkt nach dem formen ins siedende Wasser werfen. |
| | |
| | **Schritt 5 — Backofen vorheizen** |
|  | Backofen mit ofenfester Schüssel auf ca. 60-70°C vorheizen. |
| | |
| | **Schritt 6 — Portionenweise Kochen** |
|  | Einen großen Topf mit Salzwasser zum Kochen bringen und die Hitze reduzieren, bis das Wasser nur noch leicht siedet. Die Gnocchi portionsweise hineingeben. Sobald sie an der Oberfläche schwimmen, sind sie fertig. |
| | |
| | **Schritt 7 — Gnocchi aufschichten und warmhalten** |
| 150g Parmesan oder Sprienz, 150-200g Butter | Fertige Gnocchi mit einer Schaumkelle aus dem Waser entnehmen und schichtweise in die aufgewärmte Schüssel geben. Dann mit Parmesan bestreuen und mit geschmolzener Nuss-Butter beträufeln. Zurück in den Ofen bis zur nächsten Portion. |

---

## Anmerkungen

> Gnocchi Reste können im Kühlschrank gut einen Tag aufbewahrt und im Ofen oder der Mikrowelle wieder aufgewärmt werden.
