# New York Cheesecake

Author: Stefan

| | |
| --- | --- |
| **Kategorie** | vegetarisch |
| **Portionen** | 16 Stück |
| **Vorbereitungszeit** | 30 Minuten |
| **Kochzeit** | 75 Minuten bei 180°C/90°C |

---

## Zutaten und Zubereitung

| Zutaten | Zubereitung |
| :--- | :--- |
| | **Schritt 1 — Boden vorbereiten** |
| Backpapier | Springform (24-26 cm Durchmesser) mit Backpapier auslegen. |
| Alufolie für die Form | |
| 225 g Vollkorn-Butterguetzli, fein zerkrümelt | Guetzlikrümel mit der flüssigen Butter und dem Salz mischen. Auf dem Formenboden verteilen und mit einem Löffelrücken andrücken. |
| 80 g Butter, flüssig | |
| 1 Prise Salz | |
| | |
| | **Schritt 2 — Wasserbad und Ofen vorbereiten** |
| | Die Springform aussen gut mit Alufolie einwickeln, damit kein Wasser eindringen kann. Ein grosses Ofenblech oder eine passende Form 2-3 cm hoch mit Wasser füllen und in der Mitte des Ofens einschieben. Den Ofen auf 180°C Heissluft/Umluft (Ober-/Unterhitze 200°C) vorheizen. |
| | |
| | **Schritt 3 — Füllung anrühren** |
| 800 g Frischkäse | Frischkäse, Zucker, Vanillezucker und Maisstärke in einer Schüssel mit dem Schwingbesen verrühren. Crème fraîche und Eier darunterrühren. |
| 200 g Zucker | |
| 1 Päckchen Vanillezucker | |
| 50 g Maisstärke | |
| 500 g Crème fraîche | |
| 6 Eier | |
| | |
| | **Schritt 4 — Cheesecake backen** |
| | Die Füllung auf den Guetzliboden geben und in der Mitte des vorgeheizten Ofens 15 Minuten backen. Die Ofentemperatur auf 90°C reduzieren und den Kuchen 60-65 Minuten fertig backen. Der Cheesecake sollte in der Mitte noch leicht weich sein. |
| | |
| | **Schritt 5 — Ruhen und kühlen** |
| | Den Cheesecake 1-2 Stunden im ausgeschalteten, leicht geöffneten Ofen ruhen lassen. Herausnehmen, auskühlen lassen und über Nacht zugedeckt kühl stellen. |

---

## Anmerkungen

> In New York wird der Kuchen mit Schlagrahm serviert.
> Der Cheesecake hält sich 4-5 Tage zugedeckt im Kühlschrank.
